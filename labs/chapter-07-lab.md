# Chapter 7 Lab: Encryption, Data Protection & Network Security Controls

**Estimated time:** 30 minutes

## Exercise

Read-and-understand walkthrough: design VPC Service Controls perimeters and a CMEK key rotation policy for EHR Healthcare's BigQuery and Cloud Storage datasets containing sensitive patient data

## Key takeaway

Compliance architecture layers encryption, network perimeters, and data inspection controls on top of IAM, because IAM alone cannot prevent data exfiltration.
