# Chapter 3 Lab: Networking, Multi-Region HA & Disaster Recovery Design

**Estimated time:** 30 minutes

## Exercise

Read-and-understand walkthrough: design a hybrid network for EHR Healthcare connecting three on-prem clinics to GCP using Shared VPC and Dedicated Interconnect with failover Cloud VPN

## Key takeaway

Network topology decisions hinge on whether the requirement is centralized administration (Shared VPC), throughput/latency guarantees (Interconnect), or global reach (multi-region load balancing).
