## Chapter 12 Cheat Sheet: 120-Minute Exam Strategy

### Time Budget Baseline
| Question Count | Total Time | Avg Time/Question |
|---|---|---|
| 50 | 120 min | 2.4 min |
| 60 | 120 min | 2.0 min |

Reserve extra buffer minutes for case-study blocks — they need one-time upfront reading, not per-question re-reading.

### Question Type Triage
| Type | Signal | Strategy |
|---|---|---|
| Standalone scenario | No shared background doc | Answer immediately, don't over-analyze |
| Case-study-linked | References a numbered case study | Skim question stems first, read case study once, answer the whole block |
| Multiple-select | Says 'select all that apply' style (rare/avoid on this cert style) | All-or-nothing scoring — same weight as single-answer, no partial credit |

### Elimination Technique
1. Identify the requirement keyword in the stem: **cost**, **latency**, **compliance**, **minimal ops/managed**, **scalability**.
2. Eliminate any option that ignores or contradicts that keyword.
3. If two options remain valid, re-check the keyword — it almost always breaks the tie.
4. Never pick based on option order, price extremes, or 'enterprise-sounding' names alone.

### Flagging Strategy
| Situation | Action |
|---|---|
| Genuinely 50/50 uncertain | Flag, answer your best guess anyway, move on |
| Mildly unsure but leaning one way | Don't flag — trust first read, save flags for true toss-ups |
| Running low on time with flags remaining | Prioritize standalone flagged Qs over case-study-linked ones (lower re-context cost) |

### End-Game Time Management
- **Never leave a question blank** — unanswered = automatic 0, same as wrong.
- With <20 min left and unanswered questions remaining: divide time evenly across all remaining questions first.
- Only spend leftover/surplus time on flagged/hardest items after all questions have an answer.

### Post-Exam (Practice) Review Workflow
1. Tag every missed question by domain.
2. Compute miss rate per domain (e.g., 6/8 missed in Security & Compliance vs 2/10 in Reliability).
3. Restudy the domain with the **highest miss rate** first using domain-specific question sets.
4. Re-attempt a full simulation only after targeted restudy — avoid re-taking the identical exam (memorization risk).

### Final Case-Study Review Checklist
For each of the 4 case studies, confirm you can state from memory:
- Company background & industry
- Business requirements (2-4 bullet points)
- Technical requirements (2-4 bullet points)
- Existing environment constraints (legacy systems, compliance, budget)

A one-page summary per case study beats verbatim memorization — the full text is provided during the exam, but fast constraint recall saves minutes per linked question.
