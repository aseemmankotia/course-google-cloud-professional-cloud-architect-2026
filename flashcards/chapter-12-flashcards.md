## Chapter 12: Full Exam Simulation & 120-Minute Time-Management Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Total exam duration and typical question count for Professional Cloud Architect exam? | 120 minutes, ~50-60 questions. Baseline pace ≈2-2.4 min/question, adjusted for case-study blocks. |
| 2 | How many official case studies are used on the PCA exam? | 4 case studies. Exam tip: know each one's background, business requirements, technical requirements, and existing environment before test day. |
| 3 | Scoring rule for multiple-select questions on the PCA exam? | All-or-nothing: every correct option must be selected with no incorrect ones for credit. No partial credit. Same point weight as single-answer questions. |
| 4 | First action when a new case-study question block appears and you're behind schedule? | Skim the attached question stems first to know what to look for, then read the case study once fully — don't re-read the document per question. |
| 5 | Best triage order when reviewing flagged questions with limited remaining time? | Standalone (non-case-study) flagged questions first — faster to resolve from recall. Case-study-linked flags cost more time to re-contextualize. |
| 6 | Elimination technique when two options both seem valid for a single-answer question? | Re-read the stem for the optimization keyword (cost, latency, compliance, managed/ops overhead) — it resolves the tie between the two options. |
| 7 | Is there partial credit for unanswered exam questions? | No — unanswered = 0 points, same as a wrong answer. Always select something before time runs out, even a guess. |
| 8 | What should a case-study 'cheat sheet' summary include? | One page per case study: company background, business requirements, technical requirements, and existing environment/constraints. |
| 9 | Post-exam review priority when missed questions cluster in one domain? | Prioritize targeted restudy on the domain with the highest miss rate before re-attempting a full simulation. |
| 10 | Time-budget math for 120 minutes across 50-60 questions? | 120÷50=2.4 min, 120÷60=2.0 min → budget ~2-2.4 min/question average, reserving buffer minutes for case-study reading overhead. |
| 11 | Common mistake with the exam interface's flag-for-review feature? | Flagging too many questions and running out of time to revisit any of them; flag sparingly and only true toss-ups. |
| 12 | Time-remaining rule of thumb when questions are still unanswered near the end? | Never leave a question blank — divide leftover minutes across all remaining unanswered questions first, then spend any surplus on flagged/hardest ones. |
